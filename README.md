# Phaser’s First Game

My game, built one mission at a time in Game Builder Lab.

- `game.js`: my code. Each `// Mission` comment marks the code from that mission.
- `index.html`: the page that runs the game.
- `assets/`: the pictures.
- `phaser.min.js`: the Phaser game engine (see `PHASER-LICENSE.md`).
- `.lab/progress.json`: lets Game Builder Lab pick up where I left off.

## Play it

Turn on GitHub Pages (Settings → Pages → Deploy from a branch → `/ (root)`), or run `python3 -m http.server` in this folder and open http://localhost:8000.

## Try a remix

Make a branch (for example `faster-bombs`), change one rule in `game.js`, and play it. The main branch keeps the original.
